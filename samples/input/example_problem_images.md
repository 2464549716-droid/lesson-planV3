# 示例例题图片说明（Path B 输入）

本文件描述 Path B 所需的例题图片输入格式，供准备示例输入参考。

---

## 图片要求

| 项目 | 要求 |
|------|------|
| 格式 | `.png` 或 `.jpg` |
| 分辨率 | 建议 1920×1080 或同等比例 |
| 内容 | 清晰显示数学题目文本、图形、选项 |
| 命名 | 建议按环节编号，如 `P1_intro.png`、`P2_example1.png` |

---

## 示例图片结构（按环节）

### 环节1：引入（1张图）

- 图片内容：课题标题 + 引入问题
- 示例：`《三视图的应用》— 同学们，这个立体图形从正面看是什么形状？`

### 环节2：例题讲解（1-3张图）

- 图片内容：例题题目 + 图形 + 选项
- 示例：`例题1：下面的图形，从正面看是什么形状？A.正方形 B.长方形 C.圆形`

### 环节3：小结（1张图）

- 图片内容：知识点总结思维导图

---

## 参考模板 Excel

Path B 需要一个参考模板 Excel（含课程信息格式），技能将基于模板生成完整教案。

模板可从公司模板库获取，或联系海外教研负责人小羊获取最新版 `V9详案模板.xlsx`。

---

## 使用示例

在 WorkBuddy 对话中 @ 上传例题图片和参考模板，并输入触发语：

> "这三张例题图片，帮我生成一个40分钟的教案，参考模板在这里"

技能将自动分析图片内容，生成8列中文教案 `.xlsx`（v4粤语详案格式）。

---

> 注：实际输入需准备真实题目图片。示例图片需 owner 在本地准备后上传。
