# 示例输出说明（samples/output/）

本目录包含 Lesson Plan V3 技能的输出 xlsx 格式示例，供审查和复用参考。

---

## 文件清单

| 文件 | 格式 | 说明 |
|------|------|------|
| `example_output_pathB.xlsx` | `.xlsx` | Path B 输出示例（8列中文教案，v4粤语详案格式） |
| `example_output_pathA.xlsx` | `.xlsx` | Path A 输出示例（中英双语并列，绿底英文列） |
| `OUTPUT_SPEC.md` | `.md` | 本说明文件 |

---

## example_output_pathB.xlsx 格式说明

**适用场景**：Path B（例题图片 → 8列中文教案）

| 列 | 标题 | 内容 |
|-----|------|------|
| A | 环节 | 教学环节名称（引入/例题1/小结等） |
| B | 时间 | 环节时长（如 0-3min） |
| C | 角色 | 师/生 |
| D | 话术内容 | 教学话术（数字编号，学生话语放 `（）` 内） |
| E | 类型 | 破冰/引导/提问/小结/回收 |
| F | 图片 | 对应课件图片说明 |
| G | 备注 | 额外说明 |
| H | 时间戳 | 视频时间戳（如 00:00） |

**分色格式**：
- 橙黄色：引入环节
- 浅蓝色：例题环节
- 粉蓝色：小结环节

---

## example_output_pathA.xlsx 格式说明

**适用场景**：Path A（教研案 docx → 中英双语详案）

**Sheet1：课程信息**
- 4行标准：课题/年级时长/知识目标/能力目标
- 蓝底白字标题列

**Sheet2：课中详案**
- D-H列：中文话术（4列，对应4条话术）
- I列：英文话术（绿色底色 `#C6EFCE`，深绿字体 `#006100`）
- 含合并单元格和格式颜色

## 如何使用示例输出

1. 在 WorkBuddy 中触发技能（见 `REPLAY.md` 触发语）
2. 提供对应输入（Path A: docx 教研案；Path B: 例题图片 + 参考模板）
3. 检查技能生成的 xlsx 是否与示例输出格式一致
4. 验证话术序号、标注格式、中英并列格式是否正确
