# Excel 教案模板格式规范

本参考文档详细说明参考模板 Excel 的格式规范，是生成新教案时必须严格遵循的标准。

## 文件基本结构

### 列结构（共7列）

| 列索引 | 列标识 | 内容 | 建议宽度 |
|--------|--------|------|---------|
| A | 页面 | 页码标记，如 P1-P2、P4-1、P7-1 | 10 |
| B | 时间 | 该页面/环节的时间建议 | 12 |
| C | 教学目标 | 知识/能力/情感三维目标 | 24 |
| D-G | 教学设计与话术演绎 | 合并单元格，核心教学内容 | 28（每列） |

### 行结构（各模块通用）

每个模块（含破冰、环节一、环节二、环节三、总结）都遵循以下行结构：

```
[模块标题行]  ← 合并A-G列，蓝底白字，加粗，字号12
[列头行]     ← A=页面, B=时间, C=教学目标, D-G=教学设计与话术演绎
[内容行1]   ← 过渡页/例题讲解
[内容行2]   ← 继续讲解
[内容行3]   ← 小结
[内容行4]   ← 做题回收（仅例题环节）
```

## 格式定义详解

### 1. 大标题行

- **用途**：课程开头的标题，包含课题名、适用年级、课程时长
- **合并**：A1:G1（第一行，合并7列）
- **格式**：
  ```python
  workbook.add_format({
      'bold': True,
      'font_size': 14,
      'font_color': 'white',
      'bg_color': '#4472C4',
      'align': 'center',
      'valign': 'vcenter',
      'text_wrap': True,
      'border': 1
  })
  ```
- **内容示例**：`《三视图的应用》适用年级：小学三年级\n课程时长：40分钟`

### 2. 模块标题行

- **用途**：标记"课上破冰"、"环节一"、"环节二"、"环节三"、"课堂总结"
- **合并**：A列到G列（单行）
- **格式**：
  ```python
  workbook.add_format({
      'bold': True,
      'font_size': 12,
      'font_color': 'white',
      'bg_color': '#4472C4',
      'align': 'center',
      'valign': 'vcenter',
      'text_wrap': True,
      'border': 1
  })
  ```

### 3. 列头行

- **A列头**：`页面`
- **B列头**：`时间`
- **C列头**：`教学目标`
- **D-G列头（合并）**：`教学设计与话术演绎`
- **格式**（与模块标题相同，蓝底白字，字号11）

### 4. 普通单元格

- **A列**：居中对齐（页面数字）
- **B列**：居中对齐（时间）
- **C列**：教学目标内容，左对齐，垂直居中
- **D-G列（合并）**：教学设计核心内容，左对齐，垂直靠上

```python
# 普通单元格
workbook.add_format({
    'font_size': 10,
    'align': 'left',
    'valign': 'top',
    'text_wrap': True,
    'border': 1
})

# 居中对齐（用于A、B列）
workbook.add_format({
    'font_size': 10,
    'align': 'center',
    'valign': 'vcenter',
    'text_wrap': True,
    'border': 1
})

# 教学目标（用于C列）
workbook.add_format({
    'font_size': 10,
    'align': 'left',
    'valign': 'vcenter',
    'text_wrap': True,
    'border': 1
})
```

### 5. 统一行高

```python
for r in range(0, 80):
    worksheet.set_row(r, 90)
```

建议统一行高为90，确保长文本内容完整显示。

## 关键写作规范

### 教学互动话术结构

每道例题讲解必须包含：

1. **学生自主读题**：请大家认真看题，告诉老师，题目让我们做什么？
2. **教师引导观察**（2-3个问题）：
   - 这个图形/立体由几个小正方体组成？它们是怎么摆放的？
   - 如果老师站在它的正前方看过去，你会看到什么形状？
   - 那么如果老师从上面往下看呢？会与前面看到的一样吗？为什么？
3. **追问确认**：谁能告诉老师，为什么同一个立体图形，从不同方向看，形状可能不一样？
4. **教师小结**：总结本环节3条核心规律

### 学生回答标注格式

```
（引导学生回答：xxx）
```

### 知识/能力/情感三维目标格式

```
知识：掌握从不同方向（前面、上面、左面）观察小正方体组合体的方法。
能力：通过观察与连线匹配，培养空间想象力与视图转换能力。
情感：在观察与连线的活动中，体验从不同角度看事物的乐趣。
```

### 做题回收4种差异化场景

```
1. 表现突出（全对）：XX做题后主动检查了两遍，所以两题都对啦，奖励五颗小星星！
2. 有明显进步：也要表扬XX！还记得上次我们学分数时还有点迷糊，今天你全部自己分对了，每一步都特别清晰！
3. 努力但结果有误：今天最让老师感动的是XX，虽然有的题目没有完成，但是XX一直没有放弃！
4. 做题习惯不好的：我刚才看到有同学因为粗心反复订正了几次，提交之前要记得检查哦！
```

## Python 编码注意事项

- 中文字符建议使用 Unicode 转义序列（`\uXXXX`）避免 PowerShell 执行时的编码问题
- 文件开头必须声明 `# -*- coding: utf-8 -*-`
- 文件保存为 UTF-8 编码
- 合并单元格使用 `worksheet.merge_range(row, col_start, row, col_end, content, format)`
