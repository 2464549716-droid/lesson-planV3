# 教学话术模板参考

本参考文档汇集了各模块的标准话术模板，供生成教案时参考和套用。
**所有话术必须遵循教学详案标准1.0 格式。**

## 话术标准标注（必用）

| 标注 | 格式 | 用途 |
|------|------|------|
| 学生回答 | `（学生：xxx）` | 预设学生回答内容 |
| 板书 | `（板书：xxx）` | 板书内容说明 |
| 动作 | `（动作：xxx）` | 教师/学生肢体动作、课件点击操作 |
| 笔记 | `（笔记：xxx）` | 要求学生做笔记的内容 |
| 说明 | `（说明：xxx）` | 其余补充说明（如规律、公式、注意事项） |

每条话术必须标序号（1. 2. 3. 4.），每序号最多包含2个关键提问。

## 一、课上破冰话术

### 1.1 学习习惯检查

```
一、学习习惯检查
1. 出勤-表扬按时出勤
2. 作业-表扬作业完成情况
3. 预习-表扬预习完成情况
4. 课堂规则-请大家准备好草稿纸、笔记本和小文具，端正坐姿，我们开始上课啦！
```

### 1.2 破冰互动标准模板

破冰内容采用固定结构，**禁止出现当节例题的任何具体知识点、符号或计算规则**：

```
1. 同学们好！欢迎来到今天的数学思维课堂！
（动作：点击课件，展示今日课题）

2. 之前我们学习了xxx的基本特征，有没有同学还记得呀？
（学生：xxx！）

3. 很好！看来大家都记得很清楚。
（说明：此处为固定模式，禁止出现当节例题的任何具体知识点、符号或计算规则）

4. 今天老师带来了一个超酷的新技能——xxx！准备好了吗？Let's go！
```

### 1.3 破冰引入类示例（教学详案标准1.0 格式）

```
1. 老师今天带来了一个神秘的小盒子，里面装着一堆积木。大家看看屏幕上的这个立体图形，你觉得它是由几个小正方体拼成的呢？
（学生：5个小正方体，底层有3个，中间有1个，顶层有1个）

2. 如果老师站在它的正前方看过去，你能描述一下看到的是什么形状吗？
（学生：看到了一个"L"形）

3.（动作：切换视角，展示从前面看的视图）

4. 那么如果老师站在它的上面往下看，你觉得看到的形状会与从前面的不一样吗？为什么呢？
（学生：不一样，因为从上面看看到的是底层的布局）
```

## 三、例题讲解话术（标准模板）

### 3.1 分步引导结构

每道例题讲解遵循：**读题U → 探索P → 讲解S → 回顾C**

#### 读题U

```
1. 请大家认真看题，告诉老师，题目让我们做什么？有什么特别的要求？
（学生：xxx）

2.（板书：任务一：xxx）
```

#### 探索P

```
1. 请大家仔细看着课件，自己试着找一找/想一想，xxx在哪里？
（动作：邀请学生上台，在课件上标注）

2. 你在什么位置见到了xxx？
（学生：在角上！/在顶点！）

3. 它有几个面露在外面？
（学生：三个面！）
```

#### 讲解S

```
1. 没错啦！大家看课件——xxx全部都在xxx！

2.（板书：xxx → xxx）

3. 大正方体有 → xxx 个位置

4. xxx共有 → xxx 个

5.（说明：无论大正方体是3×3×3、4×4×4还是5×5×5，规律不会变！）
```

#### 回顾C

```
1. xxx找xxx，永远记住啦！

2. xxx在正方体的xxx处。

3.（笔记：xxx → 永远xxx个，记住这个规律！）
```

### 3.2 例题全量示例（正方体表面染色—三面染色）

```
读题U：
1. 同学们，今天我们的第一个任务——找出三面都染了颜色的小正方体！
2.（板书：任务一：三面染色小正方体）
3. 大家看课件——这个3×3×3的大正方体，它的表面全部染了红色，然后被切成一块一块的小正方体。我们一起来观察一下，哪些小正方体有三个面染了颜色呢？

探索P：
1. 同学们，请大家仔细看着课件上这个拆开的正方体，自己试着找出哪些小正方体有三个面染了颜色？
（动作：邀请学生上台，在课件上圈出三面染色的小正方体）
2. 你在哪个位置见到三个面全染上色的小正方体？
（学生：在角上！/在顶点！）
3. 每个角（顶点）上的小正方体，它有几个面露在外面？
（学生：三个面！）

讲解S：
1. 没错啦！大家看课件——三面染色的小正方体全部都在顶点处！
（板书：三面染色 → 顶点处）
2. 大正方体有 8 个顶点
3. 三面染色的小正方体共有 8 个
（说明：无论大正方体是3×3×3、4×4×4还是5×5×5，顶点永远是8个！这个规律不会变！）

回顾C：
1. 三面染色找顶点，8个顶点8个块！
2. 三面染色的小正方体在正方体的8个顶点处。
3. 每个顶点上的小正方体有三个面露在外面，所以三个面都被染色。
（笔记：三面染色 → 永远8个，记住这个规律！）
```

## 四、课堂总结话术（P14 区域）

### 4.1 知识点总结（整合在 E44）

知识点总结包含两部分：互动回顾话术 + 公式小结，**两部分必须整合在同一单元格内，公式小结作为末尾**：

```
1. 同学们，今天我们一起拆解了xxx的规律！
2.（动作：点击课件，展示思维导图/总结页面）
3. 我们一起回顾一下：
· 环节一 → xxx
· 环节二 → xxx
· 环节三 → xxx

【xxx 小结】
· 公式一：xxx
· 公式二：xxx
· 公式三：xxx
```

### 4.2 个性化点评（E45）

差异化表扬话术，须结合真实情况使用：

```
（说明：教师根据本节课学生的实际表现，进行具体点评。以下为点评参考话术，须结合真实情况使用）

· 表现突出（全对）：XX今天解题速度超快，全部掌握，奖励五颗小星星！
· 有明显进步：也要表扬XX！上次还有点迷糊，今天每一步都特别清晰！
· 努力但结果有误：今天最让老师感动的是XX，虽然有的题目没有完成，但是一直没有放弃！
· 做题习惯不好的：我刚才看到有同学因为粗心反复订正了几次，提交之前要记得检查哦！
```

### 4.3 习惯提醒（E46）

```
1. 今天的作业：完成练习页P14，巩固xxx的规律。
2. 下节课预告：我们继续挑战xxx！
3.（动作：点击课件，展示下节课预告）
```
